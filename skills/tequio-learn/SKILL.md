# Tequio Learn

## Runtime and context

Use `python3 bin/tequio --project <absolute-project> --workspace <name> ...`. Select workspace explicitly from the user's task or the default `main`; never pick by modification time. Installed instructions/assets are under `.tequio/`. Read `.tequio/roles/orchestrator.md` and only relevant specialist skills. User/host instructions govern; this toolkit does not override authorization or grant tools. Keep task tokens, evidence, prompts and working notes private. Do not print secrets in summaries.

## Procedure

Read actual completion/review/experiment evidence and current guidance. Identify a repeated or material gap and its root cause; distinguish project-specific facts from reusable patterns. Update existing relevant contract/skill/reference rather than append a universal rule for every event. Preserve source evidence, applicability, alternatives and limits.

Do not modify global skills/other projects or publish without scope authorization. Local project-owned adaptations should be maintained outside installer-owned files or deliberately reconciled during upgrades. Record the changed guidance and how it is validated; absent or incomplete evidence is not a successful learning receipt.
