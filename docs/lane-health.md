# Git lane health snapshots

`inspect_lanes(project)` preserves the existing discovery fields and every registered lane field. Each lane adds `exists`, `health`, `issues` and `actual`. Registered `branch`, `path`, `worktree` and `base_commit` remain expected values; `actual` describes the checkout observed now: `repository_root`, `git_common_dir`, `branch` (null for detached HEAD), `head`, `dirty`, `index_dirty`, `worktree_dirty`, `untracked`, `conflicted` and `in_progress`.

Health is `missing` when the checkout directory is absent, `unavailable` when Git cannot inspect it (including nonrepositories, unborn HEAD, rejected symlink paths and timeouts), `foreign` when actual repository common directory or checkout root differs from the controller/registered worktree, `detached` for detached HEAD, `branch-mismatch` for another branch, `dirty` for working/index/untracked changes, or `healthy`. `issues` retains simultaneous discrepancies, in that priority order. In-progress metadata includes merge, rebase, cherry-pick, revert and sequencer markers. Conflict status comes from Git's unmerged index entries.

Dirty work can be legitimate active work. Neither `healthy` nor any other snapshot constitutes reviewed task acceptance, commit selection, integration authorization or proof that an operation stopped. Inspect the reported discrepancy and preserve the checkout; no automatic repair, branch switching, commit, merge, cleanup or task binding occurs. A removed or moved lane remains registered and is reported missing at its original path. Integration intent/immutable commit receipts are outside this interface.

Inspection strips inherited `GIT_*` settings and disables Git's optional index refresh locks. Each inspection subprocess has a five-second timeout; existing repository discovery is also bounded (30 seconds per command). Inspection writes no registry, pointer, lock or Git files. A snapshot uses several commands and can race concurrent native Git activity; final host preflight and scope review remain necessary. Symlink lane paths and Git metadata directories are refused. Shared-folder/non-Git projects retain their discovery behavior and an empty lane list.
